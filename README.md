# Borozdov Palette

A theme from the Borozdov collection. Two faces — light **Pinboard**, a white workshop desk
with pastel sticky notes, and dark **Huddleroom**, the same desk after the room has emptied
out. One bold indigo carries every accent; a different pastel marks each callout type, like a
different color of sticky note.

![Borozdov Palette in light mode](https://raw.githubusercontent.com/borozdov-obsidian-themes/palette/main/screenshots/light.png)

![Borozdov Palette in dark mode](https://raw.githubusercontent.com/borozdov-obsidian-themes/palette/main/screenshots/dark.png)

## Principles

- **A white desk, not a blank page.** Pinboard's canvas is a warm workshop grey; every card —
  callout, code pane, table, popover — sits on it as a lifted white note.
- **One bold indigo.** Links, the checked box, the caret and the filled button all share the
  same indigo; it is the only color that gets to be loud.
- **A pastel per note type.** Info, tip, warning, question and the rest each get their own
  sticky-note color — sky, mint, amber, lavender, pink, coral — mixed straight into the
  callout's own background and border, never hand-picked per face.
- **Soft shapes, one full pill.** Cards round to 20px, fields and badges to 8px; the primary
  button is the one shape that takes a full pill, the way a workshop's main action always
  stands out from the rest.
- **Developer-native type.** The platform's own sans, tracked in as headings grow; no
  embedded font, no load, no flash of unstyled text.

## Features

- Light and dark modes, following Settings → Appearance → Base color scheme
- Every callout type in its own pastel — sky, lavender, mint, amber, pink, coral — as a
  rounded sticky-note card
- Tags and the open file in the sidebar as soft indigo pills
- Quiet editing: no focus ring around the note, its title or form fields while you type;
  property names read as labels, not boxed fields
- A toggle thumb tuned per face so it never disappears against its own track
- Text colours meet WCAG contrast on both faces
- The phone layout keeps the same colours and shapes
- No embedded fonts, so the theme stays around 14 KB
- No `!important`: every rule can be overridden with a CSS snippet

## Installation

**From the community directory:** Settings → Appearance → Themes → Manage, search for
**Borozdov Palette**, then **Install and use**.

**By hand:** download `manifest.json` and `theme.css` from the
[latest release](https://github.com/borozdov-obsidian-themes/palette/releases/latest) into
`<vault>/.obsidian/themes/Borozdov Palette/`, then choose Borozdov Palette under
Settings → Appearance → Themes.
